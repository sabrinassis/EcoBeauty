# EcoBeauty 🌸 - Inteligência Circular em Skincare

Projeto integrador de Programação Front-End focado em sustentabilidade, logística reversa e inclusão socioambiental de catadores de recicláveis.

## 🚀 Links do Projeto
* *Site Oficial (GitHub Pages):*(sabrinassis.github.io/EcoBeauty/)
* *Protótipo (Figma):*(https://www.figma.com/make/w5hfSI4bXiiju0dA4wOH1i/Website-Review?t=1NUVAbexnQquuqWl-1)

## 🛠️ Recursos Implementados
* *Interface Responsiva:* Desenvolvida em HTML5 e CSS3 com sistema dinâmico de abas (Single Page Application via JavaScript).
* *Guia Educacional:* Passo a passo detalhado para higienização e descarte correto de frascos de skincare.
* *Acessibilidade:* Controle de tamanho de fonte (A+) e Modo Contraste (Modo Escuro) com persistência em cache (localStorage).
* *Assistente Virtual:* Chatbot interativo (GlowAssist) para guiar o usuário e responder dúvidas frequentes.
